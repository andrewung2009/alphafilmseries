How do I get a token? (one-time setup)

  1. Open github.com/settings/personal-access-tokens/new (sign in to GitHub first).
  2. Token name: anything, e.g. Alpha Hub Admin.
  3. Repository access: Only select repositories → Alpha-HTBB.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token and copy it (starts with github_pat_).
  6. Paste it on the left and press Sign in.
The token is stored only in this browser. You can revoke it any time on GitHub.
